=====================
Dummy Driver Overview
=====================

We implemented a "Dummy" device drivers. This is a driver that simulates a device, with some interfaces, vlans, etc.

This driver is primarily intended to test and debug web html template output. It also is a good demonstration of how to create and assign
the various Connector(), Interface() and other driver objects.

This driver can be found in *switches/connect/dummy/connector.py*
